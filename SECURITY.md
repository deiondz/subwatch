# Security policy

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could put users at risk. Use GitHub's **Security → Report a vulnerability** workflow to send a private report to the maintainers.

Include affected versions, impact, reproduction steps, and any suggested mitigation. Please allow reasonable time for investigation and remediation before public disclosure.

## Scope

Subwatch is an asset-discovery and web-reachability tool, not a vulnerability scanner. Only use it against domains you own or are explicitly authorized to assess.
